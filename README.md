# 🍽 LUMIÈRE — сайт ресторана

Портфолио-проект: современный одностраничный сайт ресторана авторской кухни с базой данных SQLite и панелью управления бронированиями.

## ✨ Возможности

- **Меню** — загружается из БД, фильтрация по категориям (закуски, салаты, горячее, десерты, напитки)
- **Бронирование столика** — форма с валидацией, данные сохраняются в SQLite
- **Панель администратора** (`/admin.html`) — таблица бронирований: номер, имя, телефон, гости, дата, время, комментарий, статус; подтверждение и удаление
- **Галерея** — сетка изображений с лайтбоксом
- **Отзывы** — просмотр и добавление через форму (сохраняются в БД)
- **Акции** — выводятся из БД
- **Контакты** — адрес, часы работы, телефон, карта
- Адаптивный дизайн, плавные анимации, лайтбокс, мобильное меню

## 🛠 Стек

- **Backend:** Node.js, Express
- **БД:** SQLite (встроенный модуль `node:sqlite`, без нативных зависимостей)
- **Frontend:** HTML5, CSS3 (Grid/Flexbox, анимации), Vanilla JS (Fetch API)

## 🚀 Запуск

```bash
npm install
npm start
```

Сайт: http://localhost:3000
Панель бронирований: http://localhost:3000/admin.html

База данных создаётся и заполняется тестовыми данными автоматически при первом запуске (файл `db/restaurant.db`).

## 📡 API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/menu` | Меню |
| GET | `/api/promos` | Акции |
| GET | `/api/reviews` | Отзывы |
| POST | `/api/reviews` | Добавить отзыв `{name, rating, text}` |
| GET | `/api/bookings` | Все бронирования |
| POST | `/api/bookings` | Создать бронирование `{name, phone, guests, date, time, comment}` |
| PATCH | `/api/bookings/:id` | Изменить статус `{status}` |
| DELETE | `/api/bookings/:id` | Удалить бронирование |
